# AJDigital Website

A modern static portfolio/learning website for AJDigital.

## Files
- `index.html` — main site
- `style.css` — design and responsive layout
- `script.js` — navigation, animations, typing effect and contact form

## Before uploading to GitHub

1. Open `script.js`.
2. Find:
   `const YOUR_EMAIL = "YOUR_EMAIL_HERE";`
3. Replace `YOUR_EMAIL_HERE` with your real email address.
4. If you want the CV button to work, upload your CV PDF into the same repository and name it:
   `AJDigital-CV.pdf`
5. In `index.html`, update the Sky AR project link if you want it to open the exact repository instead of your GitHub profile.

## Uploading
Replace the old `index.html`, `style.css` and `script.js` in your `agbloejohnteye0703-ux.github.io` repository with these files.

GitHub Pages should automatically redeploy after you commit the changes.
